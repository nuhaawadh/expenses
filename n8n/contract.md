## شكل الرد — ثابت دائماً

```json
{ "success": true,  "data": { }, "error": null }
{ "success": false, "data": null, "error": "رسالة عربية مفهومة للمستخدم" }
```

رمز HTTP هو **200 في الحالتين** ما عدا رفض المصادقة (403). حقل `success` هو الفيصل،
لأن فشل التحليل خطأ مستخدم لا خطأ سيرفر — والواجهة تعرض `error` كما هو.

## الإجراءات الخمسة

### `add` — حركة من نص عربي

```json
{ "action": "add", "text": "اليوم صرفت 20 ريال عند المصنع" }
```

يرد بـ `{ "entry": { ...الصف المخزَّن } }`. زمن نموذجي **1.6–2.5 ثانية**.

### `add_receipt` — حركة من صورة فاتورة

```json
{ "action": "add_receipt", "imageBase64": "<بلا بادئة data:>", "mimeType": "image/jpeg" }
```

المسار: رؤية Anthropic ← تحقّق ← رفع إلى درايف ← حفظ. زمن نموذجي **4–8 ثوانٍ**.

يرد بـ `{ "entry": { ..., "receipt_saved": true|false } }`.

**`receipt_saved: false` ليس فشلاً.** رفع الصورة ليس شرطاً لحفظ الحركة: لو تعثّر درايف
(اعتماد منتهٍ مثلاً) تُحفظ البيانات كاملة ويأتي الحقل `false` لتنبّه المستخدم أن
الصورة وحدها لم تُحفظ. ربط الاثنين كان عيباً في التصميم الأول وأضاع حركات صحيحة.

الحد الأقصى للصورة **5 ميجابايت** بعد فكّ الترميز، والواجهة تصغّرها إلى 1600 بكسل
قبل الإرسال لأن Vercel يرفض أي طلب أكبر من 4.5 ميجابايت.

### `list` — قراءة شهر

```json
{ "action": "list" }
{ "action": "list", "month": "2026-08" }
```

بلا `month` يرد الشهر الجاري. الرد:

```json
{
  "month": "2026-09",
  "months": ["2026-09", "2026-08"],
  "currency": "SAR",
  "entries": [ ...حركات الشهر الحيّة، الأحدث أولاً ],
  "deleted_entries": [ ...محذوفات الشهر مع أسبابها ],
  "totals": {
    "today": 0, "month": 2920, "income_month": 3700, "net_month": 780,
    "count": 12, "vat_month": 0, "balance": 780,
    "prev": { "expense": 0, "income": 0, "net": 0 },
    "change": { "expense": null, "income": null },
    "by_category": [{ "category": "مواد خام", "amount": 1250 }]
  }
}
```

- `balance` **تراكمي**: كل الدخل ناقص كل الصرف من بداية التسجيل حتى نهاية الشهر المعروض.
- `change` نسبة مئوية، و`null` حين لا يوجد شهر سابق للمقارنة — الواجهة تخفيها حينها.
- `spent_at` في `entries` بصيغة `YYYY-MM-DD` جاهزة للعرض.
- المحذوفات **مستثناة من كل الإجماليات** لكنها تُرجَع منفصلة.

### `update` — تعديل حركة

```json
{ "action": "update", "id": 13, "patch": { "amount": 95, "category": "معدات" } }
```

الحقول المسموح تعديلها: `amount`, `vat_amount`, `direction`, `category`,
`spent_at`, `vendor`, `note`. أي حقل آخر يُتجاهل.

التحقق في n8n لا في الواجهة: مبلغ ≤ 0 يُرفض، ضريبة أكبر من الإجمالي تُرفض،
تصنيف خارج القائمة يُرفض. يُكتب `edited_at` تلقائياً.

`raw_text` **لا يُعدَّل أبداً** — يبقى شاهداً على ما قيل أصلاً قبل التصحيح.

### `delete` — حذف منطقي بسبب إلزامي

```json
{ "action": "delete", "id": 13, "reason": "مكررة — سجلتها مرتين بالغلط" }
```

**لا يوجد حذف فعلي في هذا الدفتر.** الصف يبقى ويُعلَّم:
`deleted: true` + `deleted_at` + `delete_reason`.

سبب أقصر من 3 أحرف **يُرفض**. الدفتر لا يفقد سجلاً، والمحذوف يبقى مرئياً
في قسم منفصل مع سببه ووقته.

## الحماية من البيانات الوهمية

النموذج يقترح، والكود يقرر:

- **النص**: حقل `is_transaction` إلزامي في المخطط. جملة بلا مبلغ حقيقي تُرفض قبل التخزين.
- **الفاتورة**: حقل `is_receipt` إلزامي. صورة ليست فاتورة تُرفض.
- تاريخ فاتورة مستقبلي أو أقدم من خمس سنوات يُرجَع إلى تاريخ اليوم — قراءة خاطئة غالباً.
- ضريبة أكبر من الإجمالي تُصفَّر.

**لا تضع أمثلة رقمية في أوصاف حقول المخطط.** مثال `"مثال: 20"` في وصف حقل المبلغ
جعل النموذج ينسخ الرقم 20 حين لم يجد مبلغاً، فخزّن حركة وهمية بصمت.

## ملاحظات تشغيلية مكتسبة

- **مخرجات Information Extractor متداخلة تحت `output`** وليست في جذر `$json`.
- **مخرجات رؤية Anthropic** تأتي في `content[]` داخل كتلة `type: "tool_use"`،
  حقلها `input`. نستخدم `tool_choice` لإجبار المخطط بدل طلب JSON نصياً.
- **عقدة `قراءة الدفتر` تحتاج `alwaysOutputData: true`**. بدونها، جدول فاضٍ ينتج
  صفر عناصر، فلا تعمل العقد التالية ولا يُرسل أي رد — والطلب يعلّق حتى ينتهي وقته.
- **عقدة `chainLlm` لا تقبل صوراً**؛ الرؤية تتم باستدعاء HTTP مباشر لـ Anthropic.
- **إرسال العربي من curl على ويندوز يصل مشوّهاً** ما لم يُرسَل من ملف UTF-8
  عبر `--data-binary @file`. اختبار `-d 'نص عربي'` يعطي نتائج خاطئة مضلّلة.
- النموذج `claude-haiku-4-5-20251001` بحرارة 0 عبر credential Anthropic المباشر
  (تفادياً لفخ `maxTokens` في OpenRouter الذي يُرجع مخرجات فارغة).
- **دقة قراءة أسماء الموردين محدودة** في الصور منخفضة الدقة — قرأ «النخبة» كـ«البخية»
  في صورة 57 كيلوبايت. ولهذا التعديل متاح والصورة الأصلية محفوظة.
