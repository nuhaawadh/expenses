# الدفتر — واجهة المحاسبة

واجهة Next.js فوق ورك فلو n8n. تكتب حركة بالعربي (`صرفت 20 ريال عند المصنع`)
فتُستخرج حقولها وتُخزَّن، وتظهر الإجماليات فوراً.

العقد الكامل للـ API في [`../../contracts/expenses.md`](../../contracts/expenses.md).

## التشغيل محلياً

```bash
npm install
cp .env.example .env.local   # ثم عبّئ القيمتين
npm run dev
```

## متغيّرات البيئة

| المتغيّر | الوصف |
|---|---|
| `N8N_WEBHOOK_URL` | رابط الويب هوك الإنتاجي من n8n |
| `N8N_SHARED_SECRET` | قيمة هيدر `x-app-secret` |

**لا تضع بادئة `NEXT_PUBLIC_` على أيٍّ منهما.** هذه البادئة تحقن القيمة في حزمة
المتصفح، فيصير الويب هوك مكشوفاً للعالم — وتشغيله يكلّف مالاً على الإنستنس.

المتصفح يستدعي `/api/expenses` فقط، وهي المسار الوحيد الذي يقرأ هذين المتغيّرين.

## البنية

```
app/
  page.tsx                 واجهة العميل: الإدخال، الإجماليات، القائمة
  api/expenses/route.ts    البوابة الخادمية — تعرف الرابط والسر وحدها
components/
  Summary.tsx              بطاقات الإجماليات وشريط التصنيفات
  EntryList.tsx            الحركات مجمّعة حسب اليوم
lib/
  types.ts                 أنواع العقد
  format.ts                تنسيق المبالغ والتواريخ
```
